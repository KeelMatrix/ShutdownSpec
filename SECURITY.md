# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately by emailing **keelmatrix@gmail.com** or opening a private GitHub security advisory. Do not create a public issue for a vulnerability.

Useful details include the affected package version, target framework and runtime, reproduction steps or proof of concept, impact, and any suggested mitigation.

Security reports are handled best-effort. Valid issues are investigated and fixed as appropriate for the latest maintained release line.

## Supported Versions

Security fixes are prioritized for the latest released package line. Older versions may receive fixes on a case-by-case basis.

## Other Reports

Use ordinary GitHub issues for non-sensitive bugs and feature requests. Code of Conduct concerns should follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), not the security contact.
